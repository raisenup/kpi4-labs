# КПІ ч4. Якість та тестування ПЗ

Репозиторій лабораторних робіт з дисципліни **«Якість та тестування програмного забезпечення»**.

## Структура

```text
.
├── index.html                 # Головна сторінка з каталогом робіт
├── labs/
│   └── 01-ui-controls/        # Лабораторна 1: UI-елементи
├── .github/workflows/         # Автоматична публікація на GitHub Pages
└── .nojekyll
```

## Локальний запуск

Проєкт не потребує встановлення залежностей. Для локального перегляду запусти будь-який статичний сервер з кореня репозиторію:

```bash
python3 -m http.server 8080
```

Після цього відкрий <http://localhost:8080>.

## Публікація

Репозиторій налаштований для GitHub Pages через GitHub Actions. Опублікований сайт доступний за адресою:

<https://raisenup.github.io/kpi4-labs/>

У налаштуваннях репозиторію один раз обери **Settings → Pages → GitHub Actions** як джерело публікації.
